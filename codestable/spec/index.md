# Project Spec

## 这个项目是什么

NaniKore 是一个 Windows 截图 OCR 翻译工具：常驻托盘，按快捷键框选屏幕上看不懂的文字，得到中文译文，并可按需展开精讲（关键词读音词义 + 整句为什么这样译）。

## 当前状态

**尚无已实现的真相。** 项目仍是空目录，没有代码，本页因此没有可记录的当前行为。

这不是文档缺失，是项目阶段。当前一切内容都是目标或计划：

- 想知道产品最终要成为什么、哪些事明确不做、哪些方向仍在探索 → 读 `codestable/vision/index.md`
- 想知道第一轮要建什么、按什么顺序、验收条件是什么 → 读 `codestable/epics/001-o-v1-端到端穿刺/spec.md`
- 想知道技术选型的取舍过程与实测数据（库版本、CGO 状态、体积、被排除的方案及理由）→ 读 `codestable/talks/001-截图ocr翻译工具选型与边界.md`

## 何时开始填写本页

`001-o-v1-端到端穿刺` 关闭时首次写入。届时应覆盖：五个能力区域（捕获 / 选区 / 识别 / 理解 / 呈现与常驻）的实际行为、四个数据契约、provider 接口、已验证的平台边界与混合 DPI 坐标规则、四条质量约束的实测数值。候选清单见该 epic 的「合并回 Project Spec 的候选」。

在那之前，判断"现在能做什么"请直接读代码；判断"应该做什么"读 Vision 与 epic。
