## 背景与目标

在切片 3 中，我们已经实现了两阶段流式理解与会话前缀缓存复用，精讲文本以纯文本打字机流式呈现在 `ExplanationTextBox` 中。
然而，大模型输出的微结构化 Markdown（`### [词汇/短语]`、`### [语法/句型]`、`### [语境与地道表达]`）在单体多行文本框中既缺乏信息层级，也无法直接与学习闭环联动（如无法逐词一键收藏）。

本切片（切片 4）聚焦于**知识点微结构化卡片解析、正文自由划词浮窗与容错降级**：
1. **微结构化卡片流式解析器（`ExplanationParser`）**：
   - 健壮支持大模型流式输出过程中的动态 AST 增量解析，提炼词汇条目（词汇、读音/IPA、词性原形、释义）、语法条目（句型、释义剖析）与语境说明段落；
   - 兼顾容错性，对变体标记、少段或多段分隔符等进行柔性适配；
2. **原生 Fluent 卡片组展示**：
   - 替换单体文本框，在 `ExplanationExpander` 内动态渲染轻量 Fluent 卡片（词汇卡片、语法卡片、语境气泡）；
   - 每张卡片提供 `[★ 收藏]` 按钮，支持即时状态反馈；
   - 保持垂直平滑滚动与动态响应式高度（`Math.Max(160, ActualHeight * 0.45)`）；
3. **正文自由划词微型悬浮气泡（`SelectionBubblePopup`）**：
   - 在译文区、原文区或精讲区拖选文字松开鼠标时，在选区附近浮出紧凑的小气泡；
   - 包含分类切换（单词/短语/语法/备注，默认单词）、原词微调输入框、`[★ 收藏]` 按钮；
   - 点击外部、切换窗口或取消选区时，气泡自动顺滑关闭；
4. **统一收藏契约（`FavoriteContract`）**：
   - 建立 `FavoriteItem` 与收藏事件总线，点击卡片或划词收藏时通过统一通道上报并由状态栏提示反馈，为切片 5 SQLite 落地实现无缝衔接；
5. **异常与格式破坏平滑降级（Graceful Degradation）**：
   - 当大模型未遵循微结构化协议（或无法解析出任何有效卡片）时，无缝降级为纯文本/Markdown 展示，并在状态栏温和提示，绝不崩溃不错乱。

## 质量目标（ISO/IEC 25010）

- **易用性（Usability）**：
  - 微结构化卡片层次分明，读音、词性、释义一目了然，一键点击即可收藏；
  - 划词气泡不打扰阅读节奏，失焦自动关闭，支持手工修偏；
- **可靠性（Reliability）**：
  - 流式追加期间解析器保持确定性状态，大模型格式错乱时平滑降级，保证无论收到何种输出都能友好呈现；
- **性能效率（Performance Efficiency）**：
  - 流式追加时不进行全量控件暴力重绘，卡片数据按增量模型更新，消除卡顿掉帧。

## 执行痕迹与闭环成果

1. **统一收藏契约与字符串即时匹配判定 (`FavoriteContracts.cs`)**：
   - 定义 `FavoriteItem` 与 `IFavoriteService` 接口，包含 `AddFavoriteAsync`、`RemoveFavoriteAsync`、`IsFavorited(content, category)` 以及事件通知；
   - 响应主人特别建议，在 `IFavoriteService` 中原生提供忽略大小写与首尾空格的 O(1) 字符串级收藏状态命中判定；
   - 现阶段提供线程安全内存实现 `InMemoryFavoriteService`，为切片 5 SQLite 落地铺平契约。
2. **健壮的微结构化卡片流式解析器 (`ExplanationParser.cs`)**：
   - 状态机精准切分“重点词汇与短语”、“语法与句型”、“语境与地道表达”；
   - 兼顾多变体标题与缺段容错，去除外层 Markdown 符号并提取读音、词性原形与释义；
   - 支持非结构化输出探测与降级标记（`IsStructured = false`）。
3. **原生 Fluent 卡片展示控件 (`ExplanationCardView.xaml` / `.xaml.cs`)**：
   - 替换单体文本框，在 `ExplanationExpander` 内动态渲染卡片列表；
   - 词汇卡片配备独立读音与词性 Badge；词汇与语法卡片右上角配备 Fluent 星标按钮；
   - 根据字符串匹配动态渲染实心金星 `\uE735`（已收藏）或轮廓灰星 `\uE734`（未收藏），点击即时添加/取消收藏并弹出状态栏通知；
   - 若模型输出格式未命中，无缝降级为只读多行文本框并在状态栏温和提示。
4. **正文划词微型悬浮气泡 (`SelectionBubblePopup.xaml` / `.xaml.cs`)**：
   - 监听译文区 `TranslationTextBox`、原文阅读区 `SourceViewer` 及编辑区 `SourceTextBox` 的划词松鼠动作；
   - 贴合选区末端弹出迷你浮窗，提供分类下拉（单词/短语/语法/备注）、微调修改框与即时字符串判定按钮；
   - 失焦、取消选区或按下 Esc 时气泡自动平滑关闭。
5. **宿主与面板无缝接入 (`ResultPanelWindow` / `NaniKoreApp`)**：
   - 保持窗口缩放时的自适应动态高度（`Math.Max(160, ActualHeight * 0.45)`）与平滑滚动；
   - 点击收藏动作统一在状态栏产生正反馈提示；
   - 全面通过自动化无 UI 自测试，编译 0 警告 0 错误。

  - `SelectionBubblePopup` 挂载、打开时命中判定、失焦/点击外部/Esc 自动关闭；
  - `FavoriteContracts` 大小写与空白忽略匹配、事件通知与纯文本 note 分层格式。

**已知观察项（不阻断，留待后续按需优化）**：
- 流式增量采用“累积缓冲 + 全量重解析 + 卡片级增量同步”实现，解析为 O(n²) 累计代价；精讲文本量级（数 KB）下无卡顿感知，暂不引入可恢复增量解析器。
- 收藏状态栏反馈当前为 `InfoSeverity.Neutral`，文案本身即正反馈；如需更强视觉信号可在 `ResultPanelWindow` 的收藏分支切换档位。
- 卡片收藏的 note 分层格式（读音/原形/释义）由切片 5 SQLite 落地后持久化，当前 `InMemoryFavoriteService` 已保持同构契约。
