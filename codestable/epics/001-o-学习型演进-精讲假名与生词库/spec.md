# 学习型演进：精讲假名与生词库

> **读者：** 负责实现假名标注、双模原文区、两阶段精讲流、知识点收藏及 SQLite 知识库的开发者。  
> **前置讨论：** `codestable/talks/002-学习型功能演进与精讲假名收藏设计.md`。

---

## 这条线要改变什么

相对当前 `codestable/spec/index.md` 仅支持单向纯文本翻译的现状，本 Epic 将 NaniKore 升级为轻量桌面外语学习工具（兑现 Vision 中的“三十秒学会”）：
1. **原文区多模态排版与防误删双模体验**：联动 `AutoTranslate` 配置，支持“只读振假名（Ruby）排版 + 双击原地切换纯文本编辑（不全选光标定位，未修改失焦无缝还原）”；
2. **两阶段理解流（全模态 Prompt Cache 优化）**：第一阶段极速返回注音与译文，第二阶段完整复用第一轮上下文（包含 Vision 模式下的图像前缀）以保证 100% 命中大模型前缀缓存，流式展开精讲；
3. **知识卡片提炼与极简自由划词收藏**：结构化提炼高价值单词/短语/语法一键收藏；正文自由划词浮出轻量气泡（失焦自动顺畅关闭），支持原词微调与分类；大模型格式异常时平滑降级为原始 Markdown 渲染；
4. **轻量便携 SQLite 知识库**：运行目录存储 SQLite 数据库，采用极简通用的“内容 + 纯文本清晰分层标注”卡片模型，设置面板新增 `[收藏]` Tab 进行检索与管理；
5. **现代多语言 Prompt 架构与智能字集探测**：假名探测结合简体汉字互斥排查，完美支持纯汉字日文词汇注音，摒弃传统文法术语，聚焦“假名/音标 + 原形”。

- **来源 Vision**：`codestable/vision/index.md` 的“三秒看懂，三十秒学会”、“精讲结果本地留存 / 生词本”。
- **关联 spec**：`codestable/spec/index.md` 中的“翻译、结果与配置”及“尚未实现”章节。

## 质量约束（ISO/IEC 25010）

- **性能效率（Performance Efficiency）**：
  - 会话前缀一致性：第二阶段精讲请求严格保持与第一阶段完全一致的 Token/消息前缀（含图像），确保稳定命中 OpenAI、Claude、Gemini 的前缀缓存（Prompt Cache），实现 >80% 输入 Token 成本减免与毫秒级首字响应；
- **可靠性（Reliability）**：
  - 容错降级：大模型输出微结构化格式损坏或不符合行规约时，禁止抛错或白屏，通过状态栏温和提示并完整渲染原始 Markdown；
  - 资产安全：SQLite 数据库独立存于应用根目录，首次收藏时惰性初始化，版本覆盖更新时不污染、不覆盖用户生词数据；
- **易用性（Usability）**：
  - 防误删编辑：双击原文进入编辑态时严禁 `SelectAll` 全选，精准定位光标；失焦且内容未改时自动还原已有的假名排版；
  - 轻量交互：正文划词收藏浮窗支持失焦自动关闭，保持顺畅阅读节奏。

## 当前怎么理解（活规格）

### 1. 原文区双模交互与振假名（Ruby）排版

```text
┌────────────────────────────────────────────────────────┐
│ [原文]                                [✎ 纯文本] [⟳ 重译]│
│  こ こ は  通[とお]れないよ                             │  ← FlowDocumentScrollViewer
│  (支持鼠标划选复制纯日文或假名，支持右键丰富复制)      │
│  [双击此处直接原地切换为纯文本 TextBox，不全选]          │
└────────────────────────────────────────────────────────┘
```

- **初始与加载生命周期（联动 `AutoTranslate`）**：
  - **已开启“OCR 后自动翻译”**：OCR 识别完成后**直接以 `FlowDocument` 呈现**，阶段 1 流式接收注音并实时排版，流式结束直接呈现完整的振假名，杜绝原生文本框到富文本的突兀跳闪；
  - **未开启“OCR 后自动翻译”**：保持原生只读/编辑 `TextBox`；用户主动点击右上角 `[翻译]` 后，才升格为假名 `FlowDocument`。
- **正常态（阅读态）**：
  - **排版形态**：使用 `FlowDocumentScrollViewer` 承载，汉字上方排布注音小字平假名/片假名（Ruby 注音）；
  - **交互与复制**：鼠标常规拖选支持直接复制日文或假名；右键菜单提供：`复制纯日文`、`复制带注音文本`（`汉字[假名]`）、`复制纯假名读音`。
- **编辑态（修正态）**：
  - **触发**：双击原文阅读区域，或点击右上角 `[✎ 纯文本]` 按钮；
  - **行为**：原地无缝切换为原生 `TextBox`，**仅将光标（Caret）定位在双击点击处，严禁全选文本（防键盘误触丢失整句）**；
  - **收拢与复原**：
    - 若用户**未修改内容**而离开焦点（`LostFocus`）或按 Esc：**立即复原原有的振假名 FlowDocument 视图**；
    - 若用户**实质修改了文本**：保持当前纯文本 `TextBox`，激活右上角 `[⟳ 重译]`；点击重译后发起新请求并更新假名。

### 2. 两阶段请求与 Multi-Turn Prompt Cache 保持

```text
[OCR 完成 / 选区截屏]
   │
   ▼ (阶段 1：极速翻译与假名，轻量流式)
┌────────────────────────────────────────────────────────┐
│ LLM Request: Base + Detected Language Prompt (+ Image) │
│ Stream Output: 假名标注原句 + ---TRANSLATION--- + 译文 │
└────────────────────────────────────────────────────────┘
   │
   ▼ (用户按需点击底部 Expander)
┌────────────────────────────────────────────────────────┐
│ LLM Request: 完整复用阶段 1 的 Messages 历史 (含原图像) │
│              + User: "请对上述内容进行深度精讲拆解。"  │
│ Stream Output: 单词/短语/语法微结构化 Markdown 流式打字│
└────────────────────────────────────────────────────────┘
```

- **统一 Session 抽象**：
  - 维护 `TranslationSession`，持有 `List<ChatMessage>`；
  - 无论 `local_ocr`（纯文本）还是 `vision_oneshot`（多模态图像），阶段 2 均完整携带阶段 1 的输入（包括图像二进制）与 Assistant 回复作为前缀历史，保证 Token 序列完全前缀匹配，命中大模型 Prefix Caching 机制。
- **阶段 1 协议（翻译 + 假名）**：
  - LLM 输出极简文本标记：
    ```text
    私[わたし]は 学生[がくせい]です。
    ---TRANSLATION---
    我是学生。
    ```
- **阶段 2 协议（精讲与词法解析）**：
  - 卡片底部 `Expander`（文案：`[ 📖 精讲与语法解析 (点击展开) ]`）展开时即触发；流式打字渲染结构化卡片与语境分析。

### 3. 精讲微结构化卡片、自由划选与容错降级

#### 3.1 约定的精讲 Markdown 格式
```markdown
### [词汇/短语]
- **通る** | とおる | 动词原形 | 通过、走过。此处为可能态否定「通れない」
- **よ** | - | 终助词 | 柔化告知语气，非命令

### [语法/句型]
- **～ない** | 否定表达 | 表示“不…”、“无法…”

### [语境与地道表达]
句子语气柔和，中文译为“过不去哦”相比生硬的“不可通过”更契合口语日常场景……
```

#### 3.2 UI 渲染与混合收藏
- **自动微卡片收藏**：流式正则捕获词汇/语法条目并渲染为独立条目卡片。卡片右侧提供 `[★ 收藏]` 按钮，一键将核心词条与结构化说明写入知识库；
- **自由划词浮窗收藏**：
  - 用户在正文或译文划选文字，松开鼠标后浮出迷你工具条；
  - 浮窗包含：分类切换 Chip/ComboBox（单词/短语/语法/备注，默认单词）、选中文本编辑框（允许手动修正）、`[★ 收藏]` 按钮；
  - **失焦自动关闭**：鼠标点击窗口其它区域或取消选区时，浮窗顺滑淡出消失，不打扰阅读；
- **容错降级（Graceful Degradation）**：若大模型输出格式未命中规约，`StatusBar` 温和提示“未能完全识别为结构化卡片，已展示原始排版精讲”，全文降级为常规 Markdown 渲染。

### 4. 客户端字符集探测与多语言 Prompt 架构

#### 4.1 纯汉字日语启发算法（解决纯汉字误判）
```text
OCR 文本
   │
   ├── 包含平假名/片假名 ([\u3040-\u309F\u30A0-\u30FF])? ──> 确定包含 Japanese
   │
   ├── 纯 CJK 汉字（无假名）?
   │      │
   │      ├── 包含简体中文独占字（如“这、个、们、时、经、让、从、说”等）? ──> 判定为中文，不注入注音
   │      └── 未命中简体独占字 且 用户处于日中翻译偏好? ──> 判定为纯汉字日文，注入日语注音插件提示词
   │
   └── 包含 Latin 字母单词? ──> 标记包含 English
```

#### 4.2 现代实用语言学规范
- **日语**：严禁出现“未然形”、“连用形”等过时复杂的传统学校文法术语；统一收敛为 **振假名标注 (`汉字[假名]`) + 动词原形（辞书形）**；
- **英语**：统一标注 **国际音标 (IPA) + 动词原形**；
- **目标语言一致性**：精讲所有释义、语法剖析文字，严格强制使用当前配置项中的 `target_language`（如中文简体）。

### 5. SQLite 便携知识库与通用卡片 Schema

- **存储引擎**：SQLite 数据库文件（`nanikore.db`），放置于应用当前根目录下（绿色便携，覆盖升级不丢数据）；首次收藏时惰性初始化；
- **数据表定义（`favorites`）**：
  ```sql
  CREATE TABLE IF NOT EXISTS favorites (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      category TEXT NOT NULL,          -- '单词' | '短语' | '语法' | '备注'
      content TEXT NOT NULL,           -- 显示的核心文本（生词、句型或划选文字）
      note TEXT,                       -- 纯文本换行分层标注（清晰分段，免去 Markdown 解析开销）
      created_at INTEGER NOT NULL      -- Unix 毫秒时间戳
  );
  ```
  *数据落库规则*：
  - **精讲卡片一键收藏**：
    - `content`：词条本身（如 `通る` 或 `～ない`）；
    - `note`：清晰的纯文本分行标注（免 Markdown 解析，直观可读）：
      ```text
      读音: とおる
      原形: 通る (动词原形)
      释义: 通过、走过。此处为可能态否定「通れない」
      ```
  - **自由划词收藏**：
    - `content`：用户划选并编辑确认的文本；
    - `note`：留空（或用户自行补充的备注文字）。
- **设置面板集成**：
  - `SettingsWindow` 新增 **`[收藏]`** Tab；
  - 顶部类别筛选（`全部` / `单词` / `短语` / `语法` / `备注`）、关键词搜索框、卡片列表流式展示、单条删除与一键复制。

## 现在推什么、先搁什么

### 可推进范围（开发切片）

1. **切片 1：多语言 Prompt 架构与智能字符集探测**
   - 客户端实现平假名/片假名探测与简体字排除启发算法，支持纯汉字日文词汇注音；
   - 提取 Base Prompt 与语言特化插件（`ja-JP`、`en-US`），定义两阶段协议；
   - 扩展配置项，支持用户自定义模板。
2. **切片 2：原文区 FlowDocument 假名排版与双模无缝切换**
   - 实现支持汉字上方注音的只读渲染，支持拖选与右键多格式复制；
   - 联动 `AutoTranslate` 配置，实现双击原地 TextBox 编辑（不全选光标定位，未变失焦复原，改变提示重译）。
3. **切片 3：全模态两阶段流式与 Session 缓存复用**
   - 抽象 `TranslationSession`，阶段 2 完整回放阶段 1 图文历史以命中 Prompt Cache；
   - 底部 `Expander` 展开即触发第二阶段流式输出。
4. **切片 4：微结构化卡片解析、正文划词浮窗与降级渲染**
   - 正则流式捕获词汇/语法条目渲染为卡片，集成 `[★ 收藏]`；
   - 实现正文划词浮动小气泡（失焦自动关闭）；接入异常降级与状态栏通知。
5. **切片 5：SQLite 极简本地知识库与设置面板 [收藏] Tab**
   - 运行时根目录惰性建库（SQLite），实现通用的 `favorites` 增删查；
   - 在设置面板中搭建轻量管理 Tab（类别过滤、搜索、删除、复制）。

### 暂不推进 / 悬挂项

- **Anki 导出**：导出为 `.apkg` 牌组或 TSV 格式（留待后续独立 issue）；
- **独立浮窗/看板模式**：已明确放弃，统一收归设置面板；
- **本地词典分词器（MeCab 等）**：由 LLM 一并处理，避免引入额外数十兆依赖。
