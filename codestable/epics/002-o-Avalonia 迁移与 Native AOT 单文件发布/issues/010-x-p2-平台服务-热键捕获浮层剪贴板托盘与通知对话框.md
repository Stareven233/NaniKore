## 目标

落实 Epic 002 P2 平台服务批次的所有要求：
1. **全局热键（脱离 WinForms `NativeWindow`）**：
   - 落地穿刺 6 验证通过的纯 Win32 `Win32HotkeyHost`（独立 STA 线程 `HWND_MESSAGE` 消息窗口）；
   - 支持热键注册、分发（`MOD_NOREPEAT`）、冲突拦截（错误码 1409 异常）与录制期注销三态；
   - 函数指针回调完全兼容 NativeAOT，零委托分配与零 ILC 警告。
2. **屏幕捕获与 PNG 编码（脱离 `System.Drawing` 与 GDI+）**：
   - 落地 `DesktopCapturer`（Win32 `BitBlt` 抓取全虚拟桌面，Top-down DIB 直灌 `SKBitmap`，含无头环境回退）；
   - 重写 `PngEncoder` 统一使用 SkiaSharp 无损保留 Alpha 编码。
3. **选区几何与浮层窗口**：
   - `SelectionGeometry` 采用 Avalonia `PixelPoint` / `PixelSize` / `PixelRect` 纯几何计算；
   - 落地 Avalonia 版全屏无边框自绘选区浮层 `SelectionOverlayWindow`，HWND 强制物理对齐全虚拟屏幕，支持 1:1 鼠标拖拽、四分暗色蒙版与尺寸标签。
4. **剪贴板网关与输入获取（脱离 WinForms `Clipboard`）**：
   - 重写 `IClipboardGateway` 实现为纯 Win32 API（`OpenClipboard`、`GetClipboardSequenceNumber`、`GetClipboardData`、`SetClipboardData` 等）；
   - 保留文本、位图与自定义格式全量快照与还原能力，消除对 STA 单元与 COM 代理的生命周期依赖。
5. **托盘宿主与通知小窗（落实裁决 11）**：
   - 采用 Avalonia `TrayIcon` + `NativeMenu`（系统原生菜单）；
   - 自绘 `WS_EX_NOACTIVATE` 提示小窗 `TrayNotificationWindow`（底角贴边定位 + 定时淡出），彻底替代气泡通知，保证 7 个警告调用点在无窗口场景完全可达。
6. **应用图标与主题化对话框**：
   - `ApplicationIcon` 统一加载 Avalonia `WindowIcon`；
   - 落地 Avalonia 版 `MessageDialog`（Route A 主题化深浅色对话框）。
7. **自测重接与全绿保障**：
   - 恢复 `SelfTest.Input.cs` 并重接 `RunInputTests()`；
   - 编译与自测全绿，NativeAOT 发布通道验证通过。

## 结论（2026-11-02）

**P2 平台服务批次目标全部达成，平台底座彻底脱离 WinForms/WPF 双引擎。**

1. **全局热键纯 Win32 化**：`Win32HotkeyHost` 与 `GlobalHotkeyWindow` 就位，依托专有 STA 线程与无反射函数指针承载，完美支持注册、连发抑制（`MOD_NOREPEAT`）、1409 占用拦截与动态注销。
2. **屏幕捕获与 PNG 编码 Skia 化**：`DesktopCapturer`（BitBlt → DIB → `SKBitmap`）与 `PngEncoder`（SkiaSharp 无损编码）就位，支持多显示器负坐标虚拟屏幕，并包含无交互会话自动内存 DC 回退。
3. **选区浮层 Avalonia 原生化**：`SelectionOverlayWindow` 依托底层 HWND 强制对齐覆盖全虚拟桌面，实现 1:1 物理像素拖框与暗色蒙版自绘；旧版 `SelectionForm.cs` 正式删除。
4. **剪贴板纯 Win32 化**：`Win32ClipboardGateway` 完全取代 `WinFormsClipboardGateway`，通过纯原生 API 驱动 `UnicodeText`、`Bitmap` 与自定义格式的多格式完整 round-trip，解除了对 Windows Forms COM 代理与 STA 上下文的强制依赖。
5. **托盘与通知小窗定案（裁决 11）**：`TrayIconHost` 成功切换至 Avalonia `TrayIcon` + 原生系统菜单；通过具备 `WS_EX_NOACTIVATE` 样式的自绘 `TrayNotificationWindow` 贴靠任务栏显示警告，保证无主窗口场景下 7 个警告调用点 100% 可达，且绝不抢占前台焦点。
6. **对话框与应用图标**：`ApplicationIcon` 统一输出 Avalonia `WindowIcon`；`MessageDialog`（Route A 主题化深浅色对话框）成功替换旧版 WPF 模态弹窗。
7. **全量自测回归全绿**：`SelfTest.Input.cs` 解除隔离并重新接入，新增捕获、几何、热键宿主与组件自测。`dev.ps1 build` 编译 0 警告 0 错误；`dev.ps1 test` 全量自测全绿通过（退出码 0）；`dev.ps1 aot` 成功生成 20.8 MB 精简 AOT exe 与 4 个旁置原生 DLL。
