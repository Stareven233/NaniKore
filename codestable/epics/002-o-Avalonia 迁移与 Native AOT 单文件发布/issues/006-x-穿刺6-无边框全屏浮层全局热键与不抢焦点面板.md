## 目标

一句话：在 `pierce/p6-overlay-hotkey-panel/` 验证 Avalonia 12 与 Windows 平台交互层面的三大窗口层级硬风险，打通**全虚拟桌面屏幕捕获与无边框置顶浮层（逐像素物理映射与暗色蒙版自绘）**、**纯 Win32 消息专用窗口承载全局热键（脱离 WinForms，支持注册/冲突拦截/录制期注销三态）**、以及**结果面板不抢焦点（`ShowActivated=false` + `WS_EX_NOACTIVATE` + `SWP_NOACTIVATE` 时序与交互保持）**，并确认在 NativeAOT 下 **0 ILC 警告**且在干净无运行时环境下自测全绿。

这是 Epic 002 的三大平台交互穿刺（spec 阻断项 6 与穿刺 6）：它不成立，跨屏截屏选区将错位、全局热键将无法脱离 WinForms 宿主、结果面板弹出时会强制抢占用户当前工作焦点的严重交互倒退。

## 结论（2026-11-01）

**穿刺 6 成立。** Avalonia 12 配合纯 Win32 P/Invoke 与 SkiaSharp 能够完美解决虚拟屏幕全覆盖自绘、无 WinForms 的独立全局热键消息泵、以及结果面板彻底不抢占焦点的需求。各项指标与契约均达到并超越原有 WPF/WinForms 双引擎水准。

五条关键技术发现与成果：

1. **虚拟屏幕 BitBlt 抓屏与 Skia 零拷贝对齐（突破 System.Drawing 依赖）：**
   - 通过 Win32 `GetSystemMetrics`（`SM_XVIRTUALSCREEN` 等）读取真实虚拟屏幕物理边界（可包含多显示器负坐标，如主屏 + 左侧副屏）。
   - 彻底摒弃 `System.Drawing.Graphics.CopyFromScreen`，通过 `CreateDC("DISPLAY", ...)` 与 `BitBlt` 捕获桌面，并利用负高度 top-down DIB（`biHeight = -height`）经 `GetDIBits` 一次性灌入 `SKBitmap.GetPixels()`，零 JIT 反射，零 GC 拷贝。
   - 发现并隔离了无交互会话限制：在 Windows 后台服务/守护进程/无头 CI 中，物理屏幕 DC 会被系统安全隔离返回 Win32 错误码 6（现有 `System.Drawing.Graphics.CopyFromScreen` 在同一环境报完全相同的错误 6），据此建立了无头自动回退检验链路。
2. **全虚拟屏幕 Avalonia 浮层窗口与 1:1 物理像素对齐：**
   - 浮层窗口采用 `WindowDecorations="None"`、`Topmost=true`、`WindowStartupLocation=Manual`。
   - 在 `OnOpened` 中通过 `TryGetPlatformHandle()` 取得 HWND，利用 `SetWindowPos(HWND_TOPMOST, virtualBounds.X, virtualBounds.Y, virtualBounds.Width, virtualBounds.Height, SWP_SHOWWINDOW)` 强制物理对齐，彻底消除多显示器混合 DPI 与负坐标错位问题。
   - 鼠标事件通过 `this.PointToScreen(e.GetPosition(this))` 将 DIP 转换为物理屏幕像素，再减去 `virtualBounds.Location`，获得与底层 `SKBitmap` 严格 1:1 逐像素重合的物理坐标，确保选区裁剪分毫不差。
   - 自绘暗色蒙版（`SelectionGeometry.GetOutsideRegions` 四分互斥矩形）、2px 纯白边框与底部居中尺寸标签（Chip）全部复刻，Esc 与右键平滑取消。
3. **脱离 WinForms 的纯 Win32 消息专用热键宿主（`Win32HotkeyHost`）：**
   - 摒弃 WinForms `NativeWindow`，使用纯 Win32 `RegisterClassExW` 与 `CreateWindowExW` 创建 `HWND_MESSAGE` 消息专用窗口，运行在专有后台 STA 线程。
   - 回调通过 `[UnmanagedCallersOnly(CallConvs = [typeof(CallConvStdcall)])]` 注册函数指针，**0 运行时代码生成，0 委托分配，0 ILC 警告**。
   - 完整支持热键生命周期三态：
     - **注册与分发**：支持 `MOD_NOREPEAT`（0x4000）防止长按热键震荡连发；
     - **冲突拦截**：重复注册或已被其他外部应用占用的热键由 Win32 返回 `1409`（`ERROR_HOTKEY_ALREADY_REGISTERED`），统一包装为具备精准提示的 `Win32Exception`，与原业务异常语义 100% 保持一致；
     - **录制期注销**：设置页录制热键时调用 `TryUnregisterHotKey` 临时释放，录制完成后平滑重新挂钩。
4. **结果面板不抢焦点（`ShowActivated=false` + `SetWindowPos` 时序打通）：**
   - Avalonia 12 原生支持 `ShowActivated = false`。
   - 结合 Win32 `SetWindowPos(HWND_TOP / HWND_NOTOPMOST, ..., SWP_NOACTIVATE | SWP_SHOWWINDOW)`：
     - 新结果展示时无论贴边定位（`PositionNearSelection`）还是提升至最上层（`BringToTopmostBand`），均绝对不会抢占当前系统的活动前台窗口（`GetForegroundWindow()` 严格保持原窗口不变）；
     - 用户在 IDE、浏览器或文本编辑器中敲击键盘绝不会被打断或吃字；
     - 允许在 HWND 句柄上动态应用与解除 `WS_EX_NOACTIVATE` 扩展样式；
     - 当用户鼠标主动点击结果面板时，事件正常捕获、文本框正常聚焦编辑、按钮正常点击响应。
5. **NativeAOT 零警告与极简产物发布：**
   - 在 `PublishAot=true` + `IlcTrimMetadata=true` + `InvariantGlobalization=true` 口径下，编译发布 **0 警告 / 0 错误**。
   - 产物恰好为 4 个文件：精简 exe 13.62 MB + 3 个旁置原生 DLL 17.97 MB（SkiaSharp 11.6 MB + ANGLE 5.4 MB + HarfBuzz 1.8 MB），目录合计 31.59 MB。
   - 在抹除 `DOTNET_ROOT` 与 `PATH` 中 dotnet 的干净隔离环境下，21 项自动化断言全部 PASS，退出码 0。

## 范围与边界

**做：**

- `pierce/p6-overlay-hotkey-panel/` 独立脚手架（不进 `src/`、不进 `NaniKore.slnx`、不被 `dev.ps1` 引用）。
- 纯 Win32 `DesktopCapturer`（BitBlt → DIB → `SKBitmap`，零 System.Drawing 依赖）。
- 跨屏物理矩形计算与归一化 `SelectionGeometry`。
- Avalonia 版全屏无边框置顶选区浮层 `SelectionOverlayWindow`。
- 纯 Win32 STA 消息专用热键宿主 `Win32HotkeyHost`（纯 P/Invoke 与函数指针）。
- Avalonia 不抢焦点结果面板 `NonActivatingPanelWindow`（`ShowActivated=false` 与 `SetWindowPos` 顶层防激活）。
- 21 条自动化确定性断言（覆盖虚拟边界、抓屏管线、选区归一化与四分蒙版面积守恒、热键注册/回调/冲突1409拦截/录制注销恢复、浮层物理映射、面板弹出前后前台窗口保护、不抢焦点定位与置顶、主动点击响应）。
- NativeAOT 发布并在干净无运行时环境下运行验证。

**不做：**

- 不碰 `src/NaniKore` 既有代码（工作树保持干净）。
- 不提前迁移整套结果面板所有复杂卡片与业务（P2/P3 批次的事）。
- 不实现 Linux/macOS 平台捕获与热键（已裁决本期仅 Windows，跨平台另开事项）。

## 结论沉淀对后续批次的影响

1. **P2（平台服务批次）基础全面落定：**
   - 屏幕捕获直接采用 `DesktopCapturer`（BitBlt → DIB → `SKBitmap`），彻底拔除 `System.Drawing.Bitmap` 与 `Graphics.CopyFromScreen`；
   - 全局热键直接采用 `Win32HotkeyHost`，彻底替换 `GlobalHotkeyWindow` 并移除 `UseWindowsForms`；
   - 选区浮层直接采用 `SelectionOverlayWindow`，替换 `SelectionForm`，保留 `SelectionGeometry` 纯几何计算。
2. **P3（结果面板批次）不抢焦点策略定案：**
   - 结果面板直接采用 `ShowActivated = false` + `PositionNearSelection` 中的 `SetWindowPos(..., SWP_NOACTIVATE)`，既不需要复杂的定时器焦点还原 Hack，也不会破坏用户主动点击与文本编辑体验。
