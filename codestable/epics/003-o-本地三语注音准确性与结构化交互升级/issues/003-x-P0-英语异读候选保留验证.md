# P0：英语异读候选保留验证

> **读者：** 负责英语词典生成和运行期查询的开发者。
> **归属：** 本文件所在路径即归属 `Epic 003`。

## 做成以后是什么样

用受控 CMUdict fixture 和现有真实源数据证明编号读音当前在哪里丢失，并验证一个不丢候选的最小数据形状：同一词面可保存多个 IPA、明确默认项及来源/变体编号。运行期能查询全部候选，同时保留当前单默认读音行为作为对照；不宣称已经具备词义、词性、上下文或英美口音消歧。

**范围：** CMUdict 解析、候选内存模型、默认项查询、候选完整性自测。
**不包含：** 英语橙色标记、右键列表、语义消歧、MisakiSharp 替换、正式 SQLite schema/哈希/分发产物切换。

## 当前证据

`PhoneticDictionaryBuilder` 已复用 `CmuDictionarySourceParser`，但正式 SQLite 仍为 `words(word PRIMARY KEY, ipa)` 单读音契约，生成时只写 `Variant=1`。因此本 Issue 只验证候选数据形状，不覆盖正式词典文件。

## 已完成执行记录

- `CmuDictionarySourceParser` 解析 `WORD`/`WORD(n)`，保留 `Variant` 和 ARPAbet；`lead`/`lead(2)`、`record`/`record(2)` 均不再在解析层丢失。
- 新增 `EnglishPronunciationCandidate` 与 `EnglishPronunciationIndex` 内存契约：同词面按稳定变体编号保存多个 IPA；`LookupAll` 返回全部候选；`Lookup` 只返回 `Variant=1`，默认项口径不因候选模型存在而改变。
- `SelfTest.Phonetics` 已用 fixture 断言 `lead`/`record` 各有 2 个候选、编号 2 可追溯、默认项为编号 1。
- 未修改正式 SQLite schema、正式 `ipa_dict.db`、哈希或下载清单。

## 本轮真实源验证（2026-11-14）

新增可复跑的 `codestable/tools/english-candidates/` 隔离工具，真实源下载到 `artifacts/english-candidates/cmudict.dict`，未覆盖生产资源。来源为 CMUdict 官方仓库 `cmusphinx/cmudict` 的 `cmudict.dict`；本次 3,618,488 字节，SHA-256 `81917843C7F44CE2B094AC63873C2C7A4CF802040792C455BA3CA406891C3D22`。源文件不提交，获取方式与许可入口见工具 README。

```powershell
dotnet run --project codestable/tools/english-candidates/EnglishCandidates.csproj -- artifacts/english-candidates/cmudict.dict
./scripts/dev.ps1 test
```

真实源探针 **15 checks / 0 failures**；主工程全量自测 **1738 checks 通过**。源码编译成功，候选 fixture、新增空白/行尾标签/候选顺序/缺默认项检查均通过。

- 135,166 行中，沿用多字母词过滤后 135,139 条读音全部进入解析器和 IPA 索引，126,026 个词面、9,113 条编号备选、8,446 个多读音词；无 `(word, variant)` 冲突，每词面恰有一个主项。
- `lead/read/wind/bass` 各两项，真实 `record` 有三项，不能将两项 fixture 当真实源完整枚举。`lead` 默认 `ˈled`、备选 `ˈliːd`；`record` 默认 `rə.ˈkɔːrd`，另有 `ˈrek.ɜːrd`、`rɪ.ˈkɔːrd`。
- 真实源包含 `# place, ...` 行尾来源说明，解析器现支持剥离该说明、首尾空白和 tab 分隔；候选查询按源编号稳定排序，大小写不敏感。不存在编号 1 时不把备选提升为默认。
- `abandoned` 直接存在于源中，不能概括为屈折词大多不存在；本 Issue 仅证明这个样本，不证明回退读音准确。
- 编号不是词义、词性或口音标签，默认不随句子变化。单字母词仍沿用原过滤，不承诺保留该范围；正式 SQLite 仍只保存默认项，9,113 条备选尚未进入发布文件。
- 单次隔离进程解析/索引约 700.20 ms，托管占用约 76.2 MB、工作集约 132.9 MB；含源数组和统计，不是生产 SQLite 成本或新性能阈值。

本轮切片达到候选模型的真实源验证目标；Issue 保持 open，未关闭或毕业。正式存储、实际屈折词读音、宿主 NativeAOT 与分发验收仍由后续切片承担。

## 当前结论与未覆盖边界

CMUdict 编号候选现在在解析层和隔离内存查询契约中可被完整保留；默认查询仍可保持既有单读音口径。该证据不等于正式运行期 SQLite 已保存候选，也不等于应用已有语境、词性或词义消歧。

仍需后续 Issue 决定正式候选 schema、迁移/重生成、实际屈折词查询边界和分发哈希。P0 未整体通过前，不替换生产词典、不上传 ModelScope、不做英语多音 UI。
