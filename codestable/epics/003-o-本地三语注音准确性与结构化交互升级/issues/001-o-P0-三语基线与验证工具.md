## 实现

`PhoneticsBaseline.csproj` 直接链接三语标注器、词典读取、过滤去重、IPA 规范化、资源清单、格式化与 Ruby 解析器；嵌入同一份策展表。OCR 路径仅提供抛错宿主适配。使用 LibNMeCab 0.10.2 与 Microsoft.Data.Sqlite 10.0.12。

`Samples.cs` 固定 22 条样本，优先沿用现有 selftest；中文补充“他还在这里”=`hái`、“把书还给我”=`huán`、“孩子长大”=`zhǎng dà`、“周长大于”的连续“长大”=`cháng dà`、银行/銀行=`yín háng`、罅缝=`xià fèng`。新增中文期望按普通话词义手工核对，未声称取得权威词典版本的逐项复核；整句其余读音和扩展字读音单列未覆盖。

`rare` 沿用长文本难词过滤；`filtered` 关闭难词筛选但保留停用词，对齐原 selftest 的银行样本；`all` 强制短文本全注观察选音。各样本独立上下文，避免跨样本去重。中文目标音仅对 BMP 字数与音节数相等的 span 投影，不伪称生产逐字映射已经存在。输出 UTF-16 spans、拼装文本与实际 Ruby 底字。

### 已复现的五项失败

| 检查 | 期望 | 实际 |
| --- | --- | --- |
| 固定银行 span 的 Ruby 挂载 | 第二段底字 `银行` | `就去银行` |
| 真实中文标注后银行的 Ruby 挂载 | `(4,2)` 对应 `银行` | `就去银行` |
| 他还在这里的“还” | `hái` | `huán` |
| 罅缝 | `xià fèng` | `xià féng` |
| `𠮷𠀀龃龉` 中 `(4,2)` 龃龉 | `jǔ yǔ` | `*,*,*,*,*,*,*,*` 被当作读音显示 |

前两项为同一根因的固定/真实链路证据：`RubyTextParser.FindBaseWordStart` 缺少原 span 起点，从“行”回溯吞入“就去”；字符串仍可满足旧 selftest，原文往返也正确。后三项分别证明默认选音和 Unicode 混排/未知 Feature 处理仍有缺陷，不在 P0 静默补词或改生产行为掩盖。

观察到简繁银行目标音、成长/周长目标音和重复混排检查通过；不能据此概括为所有简繁/上下文处理都正确。扩展字自身读音尚未核对；后续龃龉错误有独立已知期望，不因扩展字未核对而豁免。
