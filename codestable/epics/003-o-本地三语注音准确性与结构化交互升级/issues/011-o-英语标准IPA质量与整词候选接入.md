# 011 英语标准 IPA 质量与整词候选接入

**当前 G2 未通过。先推进读音质量收口，后接生产 provider 与 UI。** 骨架接入依赖 008/009；质量调查可提前开展。输入为 [穿刺报告](../../../notes/misaki-annotation-spike.md)、Misaki 原始资源与现有词典式 IPA 契约。

## 先解决质量阻断

- [ ] 确定从未丢失音位区别的数据获取词典式读音的方法；不能统一把 `ɾ` 猜成 /t/，不能因 strict converter 拒绝而接受 water/better/city 漏注。必要时修改上游数据链，不保留旧 provider 回退。
- [ ] 枚举所有符号与无效条目，验证转换不静默丢字符。现有 332,221 可转换 / 34,625 拒绝只是资源条目统计，不能作为已合格覆盖率。
- [ ] 若采用 CMU 音位来源，修正生成/读取两侧 ER0 与 IY0 等非重读元音的表达；现有 water/better 的 `ɜːr`、city 的 `iː` 不能直接作为标准答案。保持候选的来源、重音和词形信息，不能仅按变体编号推断词性。
- [ ] 固定 `I read every day.`、过去时 read、动/名词 record、`lead pipe`、屈折词、人名与未登录词等正确读音，分别判定词性和语义消歧；明确无法覆盖的边界，不能用 Rating 冒充正确率。
- [ ] 对候选验证词面/POS/来源，排除 `They/will` 这类仅句重音或弱化造成的伪多读；重音真正区分词义时必须保留。
- [ ] 将质量修复沉淀为独立可复跑金样本与失败明细；以上门槛未通过，不冻结正式英语包、不切生产、不关闭本项。

补充穿刺已证实：当前 CMU 收录 read/lead/record 的目标候选，但生产固定取首项且同读音去重，不能替代语境选择；仅修 read 的 VBP 映射会破坏过去时，仅给 lead 增加名词=/led/ 会破坏 lead role。详见[穿刺报告的 CMU 对照与修补实验](../../../notes/misaki-annotation-spike.md#补充与当前生产-cmudict-的同句对照)。CMU 作为新 provider 的正式音位来源是待验证方案，尚未冻结架构；无充分语境的输入也需明确展示政策，不能冒充可唯一消歧。

## 质量通过后接入

- [ ] 数字/货币不注，缩写仅用明确收录读法；Dr./NASA 的成功不代表任意缩写都能自动展开。
- [ ] 关闭 TTS markdown 指令与原文改写；覆盖前导空白、tab/换行、emoji/半代理项、重复词、所有格、连字符、缩写和混排的 UTF-16 对齐。
- [ ] 本句读音排首位，其他候选转换后按明确规则去重；词干候选不得冒充当前屈折形式的读音。
- [ ] 最小扩展整词候选契约与 hover 消费，不套入中文逐字列；颜色、默认项和复制/选区/收藏语义有真实 UI 验收。
- [ ] 保留过滤、10 词阈值与去重政策，覆盖 Debug/AOT、离线及闲置重建；记录真实冷/热表现。

验证：修复后的隔离金样本命令在本项补充；当前对照命令为 `./codestable/tools/misaki-annotation-probe/Invoke-Probe.ps1 -Stage All`。接入后走 `./scripts/dev.ps1 test` 与 Release 构建。当前矩阵退出 0 只是约定行为复现，不能勾选本项质量条件。
