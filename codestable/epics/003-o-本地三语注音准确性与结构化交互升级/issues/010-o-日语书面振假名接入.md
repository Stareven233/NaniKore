# 010 日语书面振假名接入

依赖 008/009。输入为带 kana 的正式日语包、现有 span/ruby 契约与过滤策略；产物为替换 IPAdic 的日语 provider，不保留旧引擎回退。

完成条件：

- [ ] 优先使用同版 UniDic kana；`東京→とうきょう`、`躊躇→ちゅうちょ`、`今日→きょう`、`凍り付く→こおりつく`，不从长音符猜书面拼写。
- [ ] 覆盖 `食べた`、`お祝い`、`買い出しに行く`、内部送假名、复合词、未知词、数字和纯假名；只有合法含汉字底字产生注音。
- [ ] 重复词、emoji、代理项、空白、换行和混排按原文 UTF-16 定位，输出区间不重叠，不重新解析方括号反推结构。
- [ ] 回归同词同音去重、同词异音、停用/难词过滤、9/10 词阈值和总开关；记录分词变化引起的差异，不机械要求旧分词数量等价。
- [ ] 真实 ruby、复制、框选、收藏不扩大底字范围；本轮日语单读候选。
- [ ] Debug/AOT 宿主、缺包、离线及闲置回收后重建行为一致。

验证走 `./scripts/dev.ps1 test` 与 Release 构建；新增金样本断言应覆盖真实 provider 和区间，临时报告放 `.temp`。隔离 Parse 通过不代表以上 UI、过滤和送假名已经通过。
