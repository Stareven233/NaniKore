# 010 日语书面振假名接入

依赖 008/009。输入为带 kana 的正式日语包、现有 span/ruby 契约与过滤策略；产物为替换 IPAdic 的日语 provider，不保留旧引擎回退。

## 交付

- `TextAnnotatorRegistry.CreateDefault()` 的 `ja` 槽位直接取 `NativePhoneticPackHost` 的原生包标注器（`Create(host)` 可注入宿主，自测因此不碰进程单例），注册表不持有该槽位——释放仍归宿主，退出时不会重复拆。
- 新增 `src/NaniKore/Phonetics/JapaneseRuby.cs`：片假名转平假名 + 词首词尾送假名回切，底字只允许「汉字 + 内部假名」且必须含汉字；`NativeTextAnnotator` 只在 `ja` 上走这条切分，过滤与去重仍按整词词面裁决。
- 旧 `JapaneseFuriganaAnnotator`（LibNMeCab + IPAdic）移出生产装配，文件留档 `.temp/010-日语/`。包引用、旧 ja 词典卡片与 NOTICE 3.1 条目按契约随旧 provider 在 014 下线。
- `NativeTextAnnotator` 增加可注入的包目录：设置页状态与真实加载从此指向同一处，注入目录缺失时真降级为纯文本（不再出现「界面说缺失、实际加载了正式包」的错位）。
- Debug 自测中三语性能预算的预热改为只重置本语言：原生包重置全部语言会把日语冷加载（约 1.3 s）卷进计时区。

## 完成条件

- [x] 优先使用同版 UniDic kana；`東京→とうきょう`、`躊躇→ちゅうちょ`、`今日→きょう`、`凍り付く→こおりつく`，不从长音符猜书面拼写。
- [x] 覆盖 `食べた`、`お祝い`、`買い出しに行く`、内部送假名、复合词、未知词、数字和纯假名；只有合法含汉字底字产生注音。
- [x] 重复词、emoji、代理项、空白、换行和混排按原文 UTF-16 定位，输出区间不重叠，不重新解析方括号反推结构。
- [x] 回归同词同音去重、同词异音、停用/难词过滤、9/10 词阈值和总开关；记录分词变化引起的差异，不机械要求旧分词数量等价。
- [x] 真实 ruby、复制、框选、收藏不扩大底字范围；本轮日语单读候选。
- [x] Debug/AOT 宿主、缺包、离线及闲置回收后重建行为一致。

命令：`./scripts/dev.ps1 build`（0 警告 0 错误）、`./scripts/dev.ps1 test`、`./scripts/dev.ps1 build -Release` + `artifacts/win-x64/NaniKore.exe --self-test`。

| --- | --- |
| 自测 | Debug 1922 项、NativeAOT 宿主 1922 项，全部通过（009 时 1911 项，本次净增 11 条日语/安装链断言） |
| 冷/热 | `ja cold=1335ms warm20=0.4–0.6ms rebuild≈1.33s`，托管堆 42 MB、工作集 334–372 MB |
| 书面假名 | `東京[とうきょう]へ行[い]く。`、`今日[きょう]はいい天気[てんき]です。`、`躊躇[ちゅうちょ]した`、`凍り付[こおりつ]く`（底字 凍り付，长音符音便 こーりつ 被拒） |
| 送假名/内部假名 | `食[た]べた`、`お祝[いわ]い`、`買い出[かいだ]しに行[い]く`、`行[い]きます`、`持ち帰[もちかえ]り`、`お茶[ちゃ]を飲[の]む` |
| 复合词 | `睡眠[すいみん]薬[やく]`（UniDic 拆成两词元，不再是旧口径的整词） |
| 未知词/数字/纯假名 | `これはiPhoneです`、`こんにちは、ふりがな` 均 0 区间；`A株100株と3.14円` 只注 `株[かぶ]`、`円[えん]` |
| 边界 | `😀東京\n　大阪😀` → `東京`(start 2) 与 `大阪`(start 6) 两个不重叠区间，`ToPlainText` 恒等 |
| 去重/异音 | `日本語を勉強する日本語` → `日本[にっぽん]語[ご]を勉強[べんきょう]する日本[にほん]語`（同词异音补标、同词同音去重） |
| UI | 结果面板短文本全注 → `日本[にっぽん]語[ご]を勉強[べんきょう]する`；长文本仍过滤 `先生/日本語/問題`；注音按钮、复制、选区与收藏不扩大底字 |
| 缺包/离线 | 指向空目录的宿主状态为「缺失」，标注器不可用、区间为空、`CountWords` 为 0、不抛异常，不回退旧引擎 |
| 安装链 | 失败→重试→首次安装即时可用；已加载语言的更新只落暂存并在重启时提升；坏暂存包整份丢弃不覆盖正式包；取消保留失败与重试入口 |

分词变化（记录，不要求旧数量等价）：`日本語 = 日本 + 語`、`睡眠薬 = 睡眠 + 薬`；词数金样本 `日本語を勉強する` 由 2 变 3。停用/常用字表仍按整词词面裁决，所以 `日本/語/問題/先生` 在仅难词模式下依旧不注。
