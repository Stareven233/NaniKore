# 009 原生 ABI、下载与资源生命周期接入

依赖 008 的可验证日语包与清单；英语 IPA 适配和整词候选由 011 完成，不阻止本项骨架工作。输入为现有后台注音/IdleResource/下载链及 [穿刺 ABI](../../../tools/misaki-annotation-probe/README.md)，产物为真实宿主的受控加载、生命周期和设置状态。

完成条件：

- [ ] 固化 ABI 版本、长度单位、错误码和同 DLL 内存释放；加载前校验受控绝对路径、哈希、架构与清单，绑定后在引擎初始化前检查 ABI 版本和必需导出，禁止同名 DLL 搜索。
- [ ] 按语种惰性加载，解析/释放/重建共用锁；首次加载、词数与注音在后台，取消和旧代请求不得回写 UI。
- [ ] 将数据释放接到现有闲置策略，解除词表、模型、tokenizer 和回退缓存引用；不卸载 NativeAOT DLL、不强制 GC/裁工作集。
- [ ] 明确失败重试与关闭顺序，覆盖并发首建、解析中回收、重复释放、重建失败后重试和取消等待。
- [ ] 设置页内置中文就绪；日英有缺失、下载中、进度、失败、就绪与重启生效状态。首次安装未加载包可即时使用；已加载包的新版本暂存并重启替换，不覆盖正在使用的 DLL。
- [ ] 缺包/哈希错/ABI 错/缺导出时保留纯文本并显示原因，翻译主链路可用；不回退旧注音引擎。
- [ ] 在真实 Debug/AOT 宿主验证闲置后重建、离线与并发，测量 exe 增量。先保持主程序现有 invariant 配置，用集成结果决定是否调整。

验证：`./scripts/dev.ps1 test`、`./scripts/dev.ps1 build -Release` 及真实宿主操作；临时报告写 `.temp`。隔离矩阵已通过只作前置证据，不替代本项验收。设置页状态与重启替换尚未实现。
