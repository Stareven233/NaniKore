# 本地三语注音准确性与结构化交互升级

> 决策：[talks/004](../../talks/004-本地三语注音优化与后续能力规划.md)；最新实测：[注音适配穿刺](../../notes/misaki-annotation-spike.md)。
> 2026-11-15 最终决策修订：仅交付中日英。日语再生书面假名；英语直接采用 Misaki 选音和已收录候选，接受有限的选音错误与候选遗漏，以 IPA 适配和整词 hover 收口。原生库架构可用不等于生产迁移完成（日语 010、英语 011 已迁移，中文内嵌 012 已交付，仅分发 014 未完成）。

## 目标与当前事实

中文保留自研 `ChinesePinyinEngine` 并改为数据内嵌；日语采用 Misaki 分词与 UniDic 3.1.0 书面假名；英语直接采用 Misaki 的本句选音与词典候选，转换为可读的美音 IPA，允许闪音 `ɾ`、喉塞音 `ʔ` 等发音变体，不强求还原词典式 /t/、/d/。英文整词 hover 展示本句选中项和其他已收录读音；有限的误选与缺项记为已知限制，不要求全面解决时态/词义消歧，也不引入第二套 CMUdict 数据链。本轮保持本地离线，数字/货币不注音，缩写仅接受明确收录的读法。5 语移至 [独立探索](../../talks/005-其他五语本地注音探索.md)。

**生产代码切换完成（012 后）。** 日语已在 010、英语已在 011 切到原生包 provider（日语书面假名 + 送假名切分，旧 IPAdic 标注器下线；英语采用 Misaki 本句选音 + 可读美音 IPA + 整词候选，旧 CMUdict 标注器下线）；中文拼音数据已在 012 随程序集内嵌，不再读外部 zh 目录。分发仍是 `PhoneticDependencies` 的 ja/en 原始词典路径，旧 en `ipa_dict.db` 与旧 zh MeCab 目录作为数据保留到 014。现有 `AnnotationSpan(Start, Length, Reading, Syllables, WholeWord)` 保留 UTF-16 区间；候选有两套互斥形状：中文逐字在 `AnnotationSyllable`，英语整词在 `WholeWordReadings`，UI 两种都能消费。

中文结构化区间、自研选音和逐字 hover 已验收；不因换 provider 重写这些逻辑。旧英语词典（`deps/phonetics/en/ipa_dict.db`）已不再被 provider 读取，但作为数据保留，本次不提前作废、删除或上传它，旧卡片与旧依赖清单随 014 下线。

## 运行与分发契约

- 正式包固定上游版本/提交、补丁、数据来源、资源白名单、SHA-256、win-x64 架构、ABI 和许可原文。Cecil 单独剥资源不足以满足新契约，允许最小源码修改。
- 中文数据随程序集内嵌，独立于外置文件；设置页中文始终内置就绪。日英按需下载到应用目录 `deps/phonetics/misaki/`，不保留旧引擎兼容/回退链。设置页最终每个语言只有一条语言包入口：009 交付期间新原生包卡片与旧词典卡片**并存是过渡态**，010/011 切换 provider 后旧 ja/en 词典下载卡片随旧 provider 在 014 下线，中文卡片在 012 内嵌后改为只读的「内置就绪」。
- ABI 用带字节长度的 UTF-8 输入和原文 UTF-16 输出偏移；定义版本、错误码、输出长度、同 DLL 的释放函数，异常不跨 unmanaged 边界。主程序按受控绝对路径加载，先校验哈希/架构/清单，绑定后在读音引擎初始化前验证 ABI 版本及必需导出。
- 解析、释放和重建共用每语锁；冷加载/重建、词数计算和注音在后台进行。取消后不回写旧结果，也不在调用进行中释放资源。
- NativeAOT DLL 不支持卸载；只释放内部数据。生产只解除引用，不强制 GC 或裁工作集。首次安装未加载包可即时使用；已加载包下载新版本后暂存，显示重启生效。
- 非 invariant DLL 已通过 invariant AOT 客户端；**不再要求主 exe 一律关闭 invariant**，009 用真实宿主确认。
- 全链保留原文和区间，不识别 TTS markdown 指令，不按读音长度猜底字；重复词、空白、emoji、代理项、所有格和混排均有回归。
- 默认读音排首位，英语候选转换后去重且不把句重音变化当异读；中文逐字在 `AnnotationSyllable`、英语整词在 `WholeWordReadings`，两套形状互斥，共用同一套 hover 视觉。
- 短文本不足 10 词豁免、停用/难词过滤和同词同音去重政策保持；分词变化引起的词数与标注差异须逐条验收。
