# 本地三语注音准确性与结构化交互升级

> 决策：[talks/004](../../talks/004-本地三语注音优化与后续能力规划.md)；最新实测：[注音适配穿刺](../../notes/misaki-annotation-spike.md)。
> 2026-11-15 修订：仅交付中日英。日语需再生书面假名，英语质量门槛未通过；原生库架构可用不等于三语迁移完成。

## 目标与当前事实

中文保留自研 `ChinesePinyinEngine` 并改为数据内嵌；日语拟用 Misaki 分词与 UniDic 3.1.0 书面假名；英语拟用语境选音与词性候选，但必须保持词典式标准 IPA。本轮保持本地离线，数字/货币不注音，缩写仅接受明确收录的读法。5 语移至 [独立探索](../../talks/005-其他五语本地注音探索.md)。

**生产代码尚未切换。** 当前日语仍为 IPAdic、英语仍为 CMUdict 多读音 SQLite、中文仍从外部数据加载。分发仍是 `PhoneticDependencies` 的 ja/en/zh 原始词典路径。现有 `AnnotationSpan(Start, Length, Reading, Syllables)` 保留 UTF-16 区间；Candidates 在 `AnnotationSyllable` 上，UI 的候选消费只支持逐字条件，英语整词候选尚需适配。

中文结构化区间、自研选音和逐字 hover 已验收；不因换 provider 重写这些逻辑。旧英语词典仍是当前生产事实，本次不提前作废、删除或上传它。

## 前置证据与放行门槛

| 门槛 | 本次结果 | 推进边界 |
| --- | --- | --- |
| G1 日语书面假名 | 通过同版数据与隔离原生样例验证 | `pron=9/kana=20`；674,791 词面、878,989 词条身份全匹配；正式链仍需固化再生和送假名/过滤回归 |
| G2 英语标准 IPA 与选音 | **未通过** | 严格转换拒绝 34,625/366,846 条读音；`I read every day.`、`lead pipe` 反例；011 必须先解决，不能直接切生产 |
| G3 按语言原生包与 ABI | 隔离通过 | 三种资源裁剪包、两种修改包，Debug/AOT 客户端、同进程和错误边界通过；宿主与正式包未验收 |
| G4 数据释放与重建 | 最小源码修改后隔离通过 | 旧对象可回收、输出可重建；DLL 常驻，生产需接闲置计时和重启更新 |
| G5 整词候选与界面 | 数据传递试验通过，UI 未实现 | 候选首项为本句读音；现有逐字条件不能消费整词候选，句重音伪多读尚需处理 |

读音转换覆盖率是资源条目口径，包含大小写增长条目和词性变体，**不是词面覆盖率或语言准确率**。矩阵通过包含原版缺陷复现，不表示 G2 通过。

## 运行与分发契约

- 正式包固定上游版本/提交、补丁、数据来源、资源白名单、SHA-256、win-x64 架构、ABI 和许可原文。Cecil 单独剥资源不足以满足新契约，允许最小源码修改。
- 中文数据随程序集内嵌，独立于外置文件；设置页中文始终内置就绪。日英按需下载到应用目录 `deps/phonetics/misaki/`，不保留旧引擎兼容/回退链。
- ABI 用带字节长度的 UTF-8 输入和原文 UTF-16 输出偏移；定义版本、错误码、输出长度、同 DLL 的释放函数，异常不跨 unmanaged 边界。主程序按受控绝对路径加载，先校验哈希/架构/清单，绑定后在读音引擎初始化前验证 ABI 版本及必需导出。
- 解析、释放和重建共用每语锁；冷加载/重建、词数计算和注音在后台进行。取消后不回写旧结果，也不在调用进行中释放资源。
- NativeAOT DLL 不支持卸载；只释放内部数据。生产只解除引用，不强制 GC 或裁工作集。首次安装未加载包可即时使用；已加载包下载新版本后暂存，显示重启生效。
- 非 invariant DLL 已通过 invariant AOT 客户端；**不再要求主 exe 一律关闭 invariant**，009 用真实宿主确认。
- 全链保留原文和区间，不识别 TTS markdown 指令，不按读音长度猜底字；重复词、空白、emoji、代理项、所有格和混排均有回归。
- 默认读音排首位，英语候选转换后去重且不把句重音变化当异读；中文逐字与英语整词候选复用同套 hover 视觉，允许最小契约扩展。
- 短文本不足 10 词豁免、停用/难词过滤和同词同音去重政策保持；分词变化引起的词数与标注差异须逐条验收。
