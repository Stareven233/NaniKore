# ff：选区浮层鼠标事件不响应 → C# 单进程重做完成

## 做了什么

重写 `pkg/overlay/selection.go`，新增 `pkg/winapi/winapi.go`，修改 `cmd/nanikore/main.go`。

## 改了哪些

**根因 1 — `event.Op` 缺失（必须修）**

Gio 的命中判定由两个独立机制合作：
- `pointer.Filter{Target: o}` 只是说"我想收哪类事件"
- `event.Op(gtx.Ops, o)` 才是在 ops 树里登记 o 的命中区域

`io/input/router.go` 处理 `ops.TypeInput` 时把 tag 挂进 hitTree；没有 `event.Op` 的 tag 永远不在命中树里，pointer 事件因此无处可投。原实现 `clip.Rect.Push()` 声明了一块区域但没有主人，`pointer.Filter` 的 Target 也就永远收不到任何事件。

修复：在每帧末尾的 `registerInput` 里先 `clip.Rect.Push`，再 `event.Op(gtx.Ops, o)`。

**根因 2 — 键盘焦点未主动请求（必须修）**

Gio 的键盘焦点不会自动落到 tag 上。不调 `key.FocusCmd` 的 tag，`key.Filter{Focus: o}` 永远收不到事件，ESC 因此无效。

修复：每帧检查 `gtx.Focused(o)`，未聚焦时执行 `gtx.Execute(key.FocusCmd{Tag: o})`。

**根因 3 — DPI 感知级别错（选区偏移，必须修）**

Gio 自己只调 `SetProcessDPIAware()`（System aware），混合 DPI 下非主屏窗口被 DWM 位图拉伸，`GetWindowRect` 与鼠标坐标都变成虚拟化后的值，导致选区偏移。需要在任何 Gio 窗口创建前就把进程声明为 Per-Monitor V2，才能拿到物理像素坐标。

修复：`pkg/winapi.SetPerMonitorV2()` 在 `main()` 最开头调用。

**窗口摆位（配合修）**

`app.Fullscreen` 在 Gio 里走 `SW_SHOWMAXIMIZED`，只覆盖一块显示器，且无边框时 `WM_NCCALCSIZE` 把客户区裁到 `WorkArea`（不含任务栏）。浮层需要与 frame 位图逐像素重合（整个虚拟桌面），所以改用 `Win32ViewEvent` 拿到 HWND 后自行 `SetWindowPos` 到物理像素坐标。

**新文件**

- `pkg/winapi/winapi.go`：`SetPerMonitorV2`、`VirtualScreenBounds`、`SetWindowFullscreenOverlay`
- `pkg/overlay/selection.go`：完整重写，新增选区压暗、边框、尺寸 chip，ESC/右键取消，`pointer.Cancel` 处理
