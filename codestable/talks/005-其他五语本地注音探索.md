# 其他五语本地注音探索

> 2026-11-15 grilling 决策：es / fr-fr / hi / it / pt-br 从 Epic 003 正式交付拆出，不参与三语 Epic 的关闭判断。

当前仅知 Misaki `EspeakG2P` 能返回整句音素串，没有逐词原文偏移和候选。上游 hi 约 53.6% 的指标是与 espeak 输出的一致性，不是自然语言发音准确率，不能据此承诺学习质量。

探索输入为固定版本 MisakiSharp、各语言自然文本金样本和明确的书面/语音输出标准。产物是分词与 UTF-16 对齐策略、标准 IPA 转换、语境影响与质量缺口报告。

立项前验证：保留原文的逐词落点、数字/缩写/连读边界、原生包独立运行、每语生命周期与实际冷/热性能，以及由熟悉该语言者核对的读音样本。整句音素不等价于逐词 ruby；分别对单词调用 G2P 可能丢语境，也必须测试。
