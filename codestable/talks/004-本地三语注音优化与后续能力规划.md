# 本地三语注音：决策与推进门槛

> 2026-11-15 审查、grilling、实测及最终取舍修订。本文记录产品决策；执行状态与验收以 [Epic 003](../epics/003-o-本地三语注音准确性与结构化交互升级/spec.md) 为准。
> 最新证据：[注音适配穿刺](../notes/misaki-annotation-spike.md)。早期 [Misaki 穿刺](../notes/misaki-spike.md) 的过强结论以本次实测纠正。

## 本轮范围

- 中文保留自研引擎，数据与日英一致放 `deps/phonetics/zh/` 按需下载（2026-11-16 主人复核后推翻原先的内嵌决定）；保留逐字候选。
- 日语采用 MisakiSharp 的分词与 UniDic 3.1.0，但必须再生书面假名字段，不能直接展示官方 `Parse().Reading`。
- 英语直接采用 MisakiSharp 的本句选音与已收录词典候选，转为可读美音 IPA，通过整词 hover 补充异读；接受有限的误选与候选遗漏，后续按反馈维护。
- 5 语另立 [探索任务](005-其他五语本地注音探索.md)，不构成本 Epic 的关闭条件，不做本轮设置页或语言包承诺。

本地注音只处理读音；释义沿用独立能力，不在本轮新增 LLM 通道。音调核、手动纠音、偏好词典、口语连读变调、TTS/OCR API 不在范围内。

## 已确认的产品决策

| 项目 | 决策 |
| --- | --- |
| 日语 | 坚持 `東京→とうきょう`、`躊躇→ちゅうちょ` 等书面振假名；允许最小上游源码和数据生成修改 |
| 英语 | 直接用 Misaki；Kokoro 编码转换为可读美音 IPA，允许 `ɾ/ʔ` 等发音变体，不强求还原词典式音位；全面时态/词义消歧不作为关闭条件 |
| 数字、货币 | 本轮不注音，仍按原文偏移定位其他词 |
| 缩写 | 仅明确收录的缩写按词典规定读法注音，其余跳过；不能拿自动拼字/展开冒充收录 |
| 候选 | 本句选中读音排首位，其他已收录读音转换后去重，通过 hover 展示；不把词典 `DEFAULT` 固定当本句默认，不承诺词典未收录读音 |
| 闲置回收 | 尽量释放词表、解析器与模型数据；DLL 常驻，不调用 `FreeLibrary` |
| 更新 | 已加载包的新版本暂存、重启生效；首次安装未加载包可即时使用；不实现旧 provider 回退 |

## 穿刺已证明什么

1. **日语原版接口不满足书面假名。** 官方生成器只保存 `pron`；UniDic 3.1.0 的 `dicrc` 中 `pron=9`、`kana=20`，不是旧 2.1.2 的第 17 列。674,791 个词面、878,989 条词条的原有词序、左右连接 ID、成本、发音均逐条匹配；补入 `kana` 后书面读音样例、偏移、原生 AOT 可用。
2. **裁剪与外置架构可行。** Cecil 剥资源后的原版日语、英语核心、英语含回退包均编成原生 DLL；最小源码修改版日英也通过 Debug/AOT 客户端、同进程加载与错误边界检查。
3. **词表可释放重建。** 最小源码修改后，日语托管存活堆约 179MB→69KB，英语约 117MB→609KB，旧实例不再存活且重建输出一致。这是显式 GC 后的可回收性观测，不是工作集下降或生产强制 GC 承诺。
4. **全局化边界在 DLL。** 非 invariant DLL 可被 invariant 和非 invariant AOT 客户端调用。主程序无需仅为语言包关闭 invariant；仍须真实宿主验证。
5. **英语存在已知局限。** 旧口径下 en-US 全量 366,846 条非空读音中，严格转换器处理 332,221 条、拒绝 34,625 条，包含合法 IPA 闪音/喉塞音。新决策允许这些发音变体，011 须修正适配器以消除 water/better/city 的人为漏注。`I read every day.` 错选 /red/、`lead pipe` 缺 /led/ 记为上游已知限制，不再要求本轮全部修复；hover 展示已收录候选。

## 实际包形态与限制

主 AOT exe 保留应用、中文自研引擎与原生 ABI 客户端；三语注音数据均不进主 exe，放 `deps/phonetics/`：日英原生包在 `deps/phonetics/misaki/`，中文拼音表在 `deps/phonetics/zh/`（约 1.5 MB）。

| 探针包 | 原生文件体积 | 限制 |
| --- | ---: | --- |
| 原版日语裁剪 | 18.98 MiB | 发音表记，不满足书面假名 |
| 修改版日语 | 20.76 MiB | 增加书面假名和释放接口 |
| 原版英语核心 | 11.29 MiB | 不含 espeak 回退 |
| 原版英语含回退 | 22.70 MiB | 美/英词典及两种回退 |
| 修改版英语含回退 | 22.64 MiB | 生命周期与原文适配通过，需按新口径完成 IPA 转换和整词 hover |

以上是本机探针实测，不是生产包上限。独立 AOT 客户端的体积不能当作主 exe 接入增量。三语注音数据都在 `deps/` 按需下载，主 exe 不因此变大；本轮不新增口音设置。

只剥资源不能解决书面假名、IPA 编码适配、原文指令处理和闲置释放。**工程路线为固定上游提交 + 可核对的最小源码补丁 + 数据再生 + 资源白名单**；Cecil 保留作对照。上游升级须检查补丁锚点、原件哈希和金样本，失配即停。英语本轮不增加第二套 CMUdict 数据来源或额外消歧模型，减少维护分支。

设置页本轮只设中文拼音、日语包、英语包三条可下载入口，形态一致；显示缺失、下载中、校验失败、就绪、重启生效等状态。清单记录路径、SHA-256、ABI、架构、大小与许可；按应用内绝对路径加载，禁止任意同名 DLL 搜索。加载前检查哈希、架构和清单，绑定后在读音引擎初始化前验证 ABI 与必需导出。

## 接口与交互约束

- UTF-8 输入带字节长度；输出 `Start/Length` 一律为原文 UTF-16 偏移。原文不改写、不接受 TTS markdown 读音指令。
- 空白、重复词、emoji、代理项、缩写、所有格、混排均须对齐回归；无法顺序定位时不猜偏移。英语不得把半个代理项返回 UI；未知或不可识别输入的处置须在 issue 中列明。
- C ABI 包含版本、错误码、结果长度与本 DLL 的释放函数。异常在边界内处理，释放与调用共用语言锁；UI 只接收当前请求结果。
- 保留 `AnnotationSpan` 区间语义与 ruby 视觉；允许最小扩展整词候选。现有候选只在逐字列条件下消费，英语 hover 需要适配。
- 本句读音排首位；其他已收录候选转换为 IPA 后去重，排除可确认仅由句重音造成的伪多读，保留 record 等真正区分词义的重音。中文候选来自自研，英语来自 Misaki 词典，日语本轮单读。
- 词数、短文本 10 词豁免、停用/难词过滤与去重沿用现有政策；分词变化逐条验收，不把分词数量变化误称等价。
- 生产闲置释放只解除引用，不强制 GC/裁工作集；锁保护解析、释放、重建和失败后的重试。冷加载与重建约秒级，必须放后台；热态快不能推导冷态毫秒级。
