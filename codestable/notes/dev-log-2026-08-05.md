### 当前问题 🔧

**选区浮层鼠标事件不响应**

**现象：**
- 窗口显示为灰色不透明（应该是半透明黑色）
- 鼠标点击和拖动完全无响应
- 日志中没有任何 "Pointer event" 输出
- 窗口事件循环正常（收到 FrameEvent, ConfigEvent）

**已尝试的方案：**
1. 使用 `pointer.Filter` + `gtx.Event()` API
2. 使用 `clip.Rect.Push()` 创建输入区域
3. 添加 `pointer.Move` 事件类型
4. 调整事件处理顺序

**可能的原因：**
- Gio v0.10.1 在 Windows 全屏模式下的已知问题
- 指针输入区域注册方式不正确
- 全屏窗口可能需要特殊的事件处理方式
- API 版本兼容性问题

**相关代码位置：**
- `pkg/overlay/selection.go:88-124` - layout() 方法的事件处理
- `pkg/overlay/selection.go:164-189` - handlePointer() 方法

### 技术笔记

**Gio API 变化：**
- v0.10.1 的事件 API 与早期版本差异较大
- `pointer.Event.Kind` 而非 `.Type`
- `app.FrameEvent` 而非 `system.FrameEvent`
- `app.NewContext()` 而非 `layout.NewContext()`
- 事件注册方式可能不同于文档示例

**热键实现关键点：**
- `RegisterHotKey` 需要在有消息队列的线程调用
- Goroutine 默认没有消息队列，需要创建隐藏窗口
- `GetMessage` 必须在主线程运行（阻塞）
- 热键回调可以异步执行（goroutine）

**GDI 捕获注意事项：**
- `screenshot.GetDisplayBounds()` 可能返回负坐标（左侧/上方副屏）
- 需要拼接所有显示器到虚拟桌面画布
- 硬件加速内容会显示为黑色（需要 DXGI）
